# DollShop

Учебный проект информационной системы онлайн-продаж и управления заказами «DollShop».

DollShop — интернет-магазин авторских коллекционных кукол, аксессуаров и сопутствующих товаров. В будущем система позволит покупателям просматривать каталог, искать товары, добавлять их в корзину и оформлять заказы, а администратору — управлять товарами и статусами заказов.

## Запуск
Откройте папку в VS Code и выполните в терминале:

```bash
python hello.py
```

Если команда `python` недоступна, попробуйте `python3 hello.py` (macOS/Linux) или `py hello.py` (Windows).
